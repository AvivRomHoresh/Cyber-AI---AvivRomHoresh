## Containerization

Explain briefly why Docker was used even though the laboratory did not use cloud services:

Docker was used to provide an isolated, consistent, and reproducible execution environment.
It ensures that the detector, simulator, and dashboard run with the same Python version, dependencies, configuration, and file mappings on every computer.

## Reflection

1. Why is a detection finding not proof of an attack?

A detection finding is based on behavior that matches a predefined rule,
but similar behavior can also occur during legitimate activity.
Therefore, the finding indicates suspicious behavior that requires further investigation,
rather than proving that an attack occurred.

2. What additional logs would help confirm the findings?

Authentication logs, firewall logs, network traffic logs, intrusion detection system logs, endpoint logs, process execution logs, and user activity logs could help confirm the findings.
These sources could show whether the login attempts or network scans were authorized and whether any successful compromise followed them.

3. What could cause a false positive?

A false positive could be caused by a legitimate user entering an incorrect password several times,
an administrator performing an authorized network scan, an automated monitoring system checking network services,
or a vulnerability scanner operating as part of approved security testing.
